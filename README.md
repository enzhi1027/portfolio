# Portfolio

웹 개발을 공부하며 일상에서 발견한 불편함을 서비스로 해결하는 데 관심을 가져왔습니다. 팀 프로젝트와 개인 프로젝트를 진행하면서 외부 API 연동, 데이터 수집·가공, 웹 기능 구현을 경험했습니다. 최근에는 AI API를 실제 서비스 기능에 적용한 경험을 바탕으로 AI와 생명과학 분야의 접점에도 관심을 넓히고 있습니다.

## Projects

### 1. matmatgotgot — 맛집 투어 플랫폼
사용자가 맛집 투어 코스를 등록하고 관리하는 팀 프로젝트입니다.

- **담당:** 코스 등록·수정, TMAP API를 활용한 이동 소요시간 표시, 지도상 코스 표시
- **기술:** Java, Spring Boot, React, JavaScript, HTML, TMAP API
- [개인 기여 내용](matmatgotgot.md) · [원본 팀 프로젝트](https://github.com/enzhi1027/matmatgotgot)

### 2. 생태관광 정보 플랫폼
외부 API로 생태관광지 정보를 수집하고 지역별 조회 및 지도 표시 기능을 제공하는 팀 프로젝트입니다.

- **담당:** API 데이터 추출·가공, 중복 판별, Spring Scheduler를 이용한 정기 갱신, 관광지 정보 페이지와 지도 시각화
- **기술:** Java, Spring Boot, React, JavaScript, HTML, Spring Scheduler, 카카오맵 API
- [개인 기여 내용](semi_project.md) · [원본 팀 프로젝트](https://github.com/enzhi1027/semi_project)

### 3. UsTwo — 커플 웹 플랫폼
커플을 위한 여러 기능을 통합한 웹 서비스 팀 프로젝트입니다.

- **담당:** 커플 가계부, Gemini API 기반 연애고사·메뉴 추천·AI 연애 상담 기능
- **기술:** Java, Spring, JSP, Servlet, MyBatis, Oracle, JavaScript, Google Gemini API
- [개인 기여 내용](FinalProject.md) · [원본 팀 프로젝트](https://github.com/enzhi1027/FinalProject)

### 4. flot — 공연 정보 통합 플랫폼
뮤지컬과 연극 정보를 한곳에서 확인할 수 있도록 기획한 개인 프로젝트입니다.

- **현재 구현:** 메인 화면, 공연 정보 표시, 일부 검색 기능
- **구상 중:** 공연 일정 통합, 티켓팅 연습, 좌석 시야 정보, 일정 관리 및 데이터 수집 자동화
- [프로젝트 상세](flot.md) · [저장소](https://github.com/enzhi1027/flot)

- 사용자의 실제 불편함을 해결하는 웹 서비스 기획 및 구현
